
## Shortcuts

`tab`: Switches to Edit mode and back (from any other mode). In the 3D viewport, when you are in another mode, pressing tab will open edit mode for the currently selected object.

`shift+A`: Add object. Works in the 3D viewport, in both object and edit mode (in edit mode, you may only add more primitive meshes).

`N`: Opens the "upper right side menu" in the 3D viewport. This menu can be used to change the transform of individual vertices, edges, and faces in edit mode, control the viewport camera, and more.

`shift+D`: Duplicate object.
