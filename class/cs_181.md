
## Definitions

**bitstrings**

represented by cartesian products. If the set of bits $A=\{0,1\}$ then the set of length n bitstrings is $A^n$.

Set of all possible bitstrings is denoted as $A^* = \emptyset \cup A \cup A^2 \cup \dots$ 

**Encoding**

An injective function that takes a thing and maps it to a bitstring.
