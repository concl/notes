Very common and important technique. When a problem has an object of interest (especially problems where you perform operations, queries, or try to find some property of different instances of the object), always try to consider some transformation on that object.

Any question or modification to the object might be easier to handle on the transformed version.

## Common transformations

Array of integers:
- prefix sum
- difference array
- sorting

Graphs:
- Traversals of a tree (preorder), used in a problem 
- Euler tour/euler path of a tree
