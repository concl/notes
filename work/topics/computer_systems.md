
Computer systems can be roughly divided into the following subfields:
- Computer Architecture
	- Concerns how hardware executes instructions and moves data
	- Processors, caches, memory, and devices
- Operating Systems
	- How programs share a machine
	- Scheduling, virtual memory, file systems, and isolation
	- On desktop systems, users often interact with the system through a graphical desktop environment.
- Programming Languages
	- How code becomes executable
	- Objects, Garbage Collection, Async
- [[computer_networking]]
	- How machines address each other, route traffic, and deliver data
- Databases
	- How to store data durably, query and update it efficiently, and handle concurrent access
- Distributed Systems
	- How multiple machines can coordinate and keep a service running even when some machines fail.
