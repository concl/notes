
## Definitions / Concepts

**Network Media**
The physical medium on which information between computers on a network is transferred. This can include optical signals in fiber optics, electrical signals in copper wire, and electromagnetic waves through the air (infrared, microwave, or radio waves).

**Clients and Servers**
Clients and servers are determined by the software installed on a computer, where clients make requests and servers receive information and send information back to the client. Some examples of client software are email applications and web browsers. Some examples of server software are web server software and email server software.


**Hosts  (End devices)**
All computers that are connected to a network and participate in network communication are called hosts. Computer hosts send and receive information over the network and can be both clients and servers.

Hosts/End devices are either the source or target of a message transmitted over the network. Hosts need to be uniquely identified over the network, so they have addresses. Whenever a host initiates the transmission of a message, it uses the address of the destination host to specify where the message should be sent.


**P2P Network**
A P2P (Peer to peer network) is a usually small network where computers can act both as clients and servers as necessary. In its simplest form, it consists of 2 computers that connect wired or wirelessly. Some drawbacks to this form of network are that it is hard to scale and less performant (due to computers being able to act as both clients and servers).


**P2P Application**
An application that uses the P2P model where every host can be both a client and server at the same time. 


**Network Infrastructure**
The base platform that supports network connections. This is physically constructed with 3 main components:
- End devices (or hosts)
- Intermediate devices
- Network media


**ISP (Internet Service Provider)**
An ISP links a home network to the internet. Some examples of ISPs are cellular networks that provide smartphone service, local cable providers, landline telephone service providers, or independent providers who lease bandwidth on a portion of the physical infrastructure of another company.

ISPs connect to each other to form a network that connects users all over the world. ISPs are connected in a hierarchical manner that generally ensures that internet traffic is transmitted over paths that are as short as possible. ISPs can provide additional services like website hosting.


**Internet Backbone**
The internet backbone connects ISP networks in major metropolitan areas all around the world. The primary medium for this is fiber optic cables. These are typically installed underground to connect cities with continents, and sometimes run under the sea to connect continents.

This backbone is a complex graph of fiber optic cables, switches, and, routers that direct the flow of information between source and destination hosts. This complexity is not typically exposed to end users; connecting to the ISP is a relatively simple process.

**Connecting to the ISP**
The simplest way to connect to the ISP is with a modem, which provides a direct connection from 1 computer to the ISP. This is typically unsafe and doesn't allow for multiple computers. In most home setups, there is a router that handles connections to multiple computers and routes their traffic to the modem which connects to the ISP.

There are multiple ways to connect to the ISP physically

Most common (requires physical infrastructure)
- Cable (coaxial cable, traditionally used for cable television)
- DSL (runs over a telephone line, only some telephone lines support it)

Less common (can be wireless)
- Cellular (Cell phone towers)
- Satellite (requires direct line of sight to a satellite which transmits information between the user and the ISP)
- Dial up telephone (slow, uses any phone line and modem). Although it also uses telephone lines, it is much slower since it only uses the narrow frequency range designed for human speech.

**Wireless Networks**
Networks that run over electromagnetic waves (the media transmitting data is space itself)

**GPS (Global Positioning System)**
The GPS uses satellites to transmit signals around the planet. When smartphones receive these signals, it can calculate its coordinates on the planet with high accuracy.


**Wi-Fi**
End devices like smartphones and laptops contain Wi-Fi transmitters and receivers which enable the connection to local networks and the internet. The device needs to be within range of a wireless network access point. A hotspot is where Wi-Fi signals are available.
