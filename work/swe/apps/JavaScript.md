## Importing (node.js)

CommonJS: `require('foo')`.

This is a synchronous function that is the default way to import modules in `node.js`

Example:
`const { app, BrowserWindow } = require('electron')`

This imports the submodules app and BrowserWindow from electron.

ES Modules: `import`

This is an asynchronous statement that imports code at compile time.
